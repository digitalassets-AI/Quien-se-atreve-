# Código de conducta

## Nuestro compromiso

Queremos un espacio respetuoso para personas de todas las edades (siempre
mayores de 18), identidades, orientaciones, experiencias y niveles técnicos.
Participar en el proyecto implica tratar a los demás con respeto.

## Comportamiento esperado

- Usar lenguaje inclusivo y respetuoso.
- Aceptar críticas constructivas.
- Respetar los límites y el consentimiento de las demás personas.
- Priorizar la seguridad y el bienestar del grupo.
- Reportar problemas de forma privada cuando corresponda.

## Comportamiento no tolerado

- Acoso, intimidación, amenazas o discriminación.
- Contenido sexual explícito, violento o no consentido.
- Publicar datos personales de otras personas sin permiso.
- Spam, ataques personales o discusiones hostiles.
- Cualquier conducta que haga sentir insegura a otra persona.

## Aplicación

Los mantenedores pueden editar, cerrar o rechazar issues, comentarios, commits y
Pull Requests que incumplan este código. Las infracciones graves pueden provocar
el bloqueo del repositorio.

Si necesitas reportar una conducta, usa **Security → Report a vulnerability** o
contacta de forma privada a **Digital Assets**.

## Alcance

Este código aplica a issues, Pull Requests, discusiones, commits y cualquier
espacio oficial del proyecto.
